# inphoraClone

A simple multi-page frontend website project built using HTML, CSS, and JavaScript.  
This project was created as a collaborative learning exercise to understand basic team workflow, Git/GitHub usage, and how real-world small websites are structured.

It is a basic static website, not a production-level product. The main focus was learning and collaboration.

---

## 🌐 Live Demo

https://pankajbadhann.github.io/inphoraClone/

---

## 📌 Project Overview

This website contains multiple pages:

- Home
- About
- Services
- Contact

All pages are connected using simple navigation and share a common design structure.

---

## 🧑‍💻 Tech Stack

- HTML5  
- CSS3  
- JavaScript (basic DOM usage)  
- Git & GitHub (for collaboration and version control)

No frameworks or libraries were used.

2. Open project folder:
   cd inphoraClone

3. Open index.html in your browser

No installation or setup required.
